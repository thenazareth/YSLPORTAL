## Introduction
This project consists of the development of an administrative portal of a learning platform for a fictional company called YouLearn (YL) . This company has an educational platform online where students around the world can register to one of its courses and learn new skills with different instructors that will teach them through the platform. <br>
The goal of this project is to reproduce a real system that would be needed in such a company to monitor key performance indicators of its users, as well as manage them. I aim to go through the entire software development lifecycle, from requirements to implementation and system documentation. <br>
This project is intended for my own self-improvement. The idea came from previous academic work in which I was responsible for building an administrative page for a similar platform to monitor users and relevant metrics related to platform usage. In this project, however, I will work independently throughout the entire process, utilizing modern web development technologies.
